# 회의 후속조치 관리 도구 (Meeting Follow-up Tracker)

회의 내용을 **결정사항**과 **조치 과제(담당자·기한·상태)** 로 구조화해 기록하고,
회의 결과 보고서를 자동 생성하며, 여러 회의에 흩어진 미완료 과제를 한 화면에서 추적하는 웹앱입니다.

- 배포 URL: `https://{프로젝트명}.vercel.app` (배포 후 기재)
- 설치·로그인 없이 브라우저에서 바로 사용
- 서버 없이 동작하며 데이터는 브라우저 localStorage에 저장

## 주요 기능

| 기능 | 설명 |
|---|---|
| 회의 관리 | 회의명·일시·장소·참석자·안건 등록/수정/삭제, 최신순 목록, 회의명 검색, 회의별 미완료 과제 수 표시 |
| 결정사항 | 회의 상세에서 한 줄씩 추가, 그 자리에서 수정·삭제, 번호 자동 부여 |
| 조치 과제 | 내용·담당자·기한·상태 등록, 참석자 기반 담당자 자동완성, 상태 즉시 변경, 완료일 자동 기록 |
| 보고서 | 정형화된 회의 결과 보고서, A4 인쇄(메뉴·버튼 숨김), 메일·메신저용 텍스트 복사 |
| 조치 현황 | 전체 미완료 과제 통합 목록, 지연(빨강)·임박(주황, 3일 이내) 강조, 담당자 필터, 요약 카드 |
| 데이터 | localStorage 자동 저장, 첫 실행 시 샘플 데이터 생성, JSON 백업 내보내기·가져오기 |

## 화면 경로

| 화면 | 경로 |
|---|---|
| 회의 목록 | `#/meetings` |
| 새 회의 / 회의 수정 | `#/meeting/new`, `#/meeting/{id}/edit` |
| 회의 상세 | `#/meeting/{id}` |
| 보고서 | `#/meeting/{id}/report` |
| 조치 현황 | `#/actions` |

## 파일 구성

```
├── index.html   # 고정 레이아웃(헤더·푸터), 본문 컨테이너
├── style.css    # 스타일, 반응형(768px), 인쇄용 CSS
├── app.js       # 상태 관리·저장소·라우팅·렌더링·이벤트
├── README.md
└── .gitignore
```

외부 라이브러리, CDN, 빌드 도구를 사용하지 않는 순수 HTML / CSS / Vanilla JavaScript 프로젝트입니다.

## 로컬 실행

간단히 `index.html`을 브라우저로 열어도 동작합니다.
클립보드 복사 등 전체 기능 확인은 로컬 서버 실행을 권장합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 배포 (Vercel)

1. 이 저장소를 GitHub에 push
2. Vercel → Add New… → Project → 저장소 Import
3. Framework Preset: **Other**, Build Command·Output Directory: 비워둠
4. Deploy

## 유의사항

- 데이터는 **현재 브라우저에만** 저장됩니다. 다른 기기·브라우저에서는 보이지 않으니 [백업 내보내기]를 활용하세요.
- 브라우저 데이터를 삭제하면 기록이 사라집니다.
- 민감한 개인정보는 입력하지 마세요.
